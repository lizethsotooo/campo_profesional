# Desarrollo móvil

## Desarrollo móvil y sus tecnologías

- JavaScript y Frameworks Modernos (React, Vue, Angular)

JavaScript es la base principal del desarrollo en el lado del cliente (frontend).

Los frameworks como React o Vue.js permiten crear interfaces interactivas mediante componentes reutilizables.

 Angular ofrece un entorno completo estructurado con TypeScript para grandes aplicaciones. 

![Logo de React](https://cdn.jsdelivr.net/npm/simple-icons@v8/icons/react.svg)

- Node.js
Es un entorno de ejecución basado en JavaScript para el lado del servidor (backend).

Utiliza un modelo de operaciones que agiliza el manejo de múltiples conexiones simultáneas.

Permite construir APIs rápidas y aplicaciones web escalables. 

![Logo de React](https://cdn.jsdelivr.net/npm/simple-icons@v8/icons/nodedotjs.svg)


- TypeScript
Es un lenguaje basado en JavaScript que añade tipado estático opcional.

Ayuda a detectar errores de código antes de ejecutar los programas.

Facilita el mantenimiento de proyectos grandes en equipos de desarrollo. 
![Logo TypeScript](https://cdn.jsdelivr.net/npm/simple-icons@v8/icons/typescript.svg)


- Python (con Django o FastAPI)
Es un lenguaje de programación muy popular por su facilidad de lectura y sintaxis limpia.

Django provee herramientas integradas para crear sitios seguros con rapidez.

Se usa mucho en proyectos que combinan la web con análisis de datos e inteligencia artificial. 

![Logo Django](https://cdn.jsdelivr.net/npm/simple-icons@v8/icons/django.svg)

- WebAssembly (WASM)
Es una tecnología que permite ejecutar código escrito en lenguajes como C, C++ o Rust directamente en el navegador web.

Ofrece velocidades de procesamiento cercanas a un programa nativo.

![Logo WebAssembly](https://cdn.jsdelivr.net/npm/simple-icons@v8/icons/webassembly.svg)
